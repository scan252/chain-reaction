# 卡牌游戏数值与机制设计调研笔记

> 调研日期：2026-09-09 · 用途：为《链式反应》P3 数值机制重构提供理论依据
> 来源：杀戮尖塔系列拆解、GDC 演讲、机核/知乎深度文章、Balatro 分析、STS2 2026 EA 实战教训

---

## 1. 胜率目标带（难度锚点）

| 指标 | 杀戮尖塔实测 | 我们的目标（休闲 Web Roguelike） |
|------|-------------|--------------------------------|
| 新手首次通关率 | ~9.6% | **35%~50%**（新手教学后首通） |
| 熟练玩家(A0)通关率 | 70%~90% | **75%+** |
| 专家玩家 | >90%（连胜展示） | 精英难度下 50%~65% |
| 技能表达空间 | 巨大（9.6%→90%+） | 中等（35%→85%），单局 20 分钟内 |

**结论**：我们的游戏是 20 分钟量级的 Web 游戏，难度应显著低于 StS（它的 9.6% 首通率建立在 5+ 小时学习曲线上），但要保留"高手显著更强"的技能斜坡。难度分级（标准/精英）承载两个端点。

## 2. 数值框架方法论

### 2.1 三层架构（数据层 → 修正层 → 结算层）
- **数据层**：卡牌/敌人/遗物的基础数值（我们的 `balance.ts` + `cardData.ts`）
- **修正层**：所有加成按 **加法 → 乘法** 顺序进入管线；乘区个数是强度的指数（StS 的力量×虚弱×多段）
- **结算层**：先扣盾后扣血；结算顺序即策略

### 2.2 价值曲线（StS 能量价值模型）
- 0 费卡 ≈ 3 点价值；每 +1 费 ≈ +2 价值（1费=5, 2费=7, 3费=9+机会成本）
- **我们的映射**：没有费用系统 → 槽位即费用。5 槽 = 5 费/回合。单槽期望价值 = DPR预算/攻击槽数。修饰卡占槽 = 投资，必须提供 ≥1.6 倍回报才值得（x2 修饰 vs 直接放一张攻击卡的机会成本）
- 生命值是一切资源的最终兑换标的：金币≈0.5HP/枚、卡牌删除≈HP保值、精英掉落≈用 HP 买上限卡

### 2.3 连携强度公式
`强度 = 基础导出 × 乘区1 × 乘区2 × ...`
- 乘区相互独立时强度指数增长 → **乘法关系的卡必须归入同一流派统一平衡**（机核：乘法数值同族原则）
- 我们的 REPEAT_NEXT × MULTIPLY_NEXT 正是两个乘区（x2 × 触发3次 = 6x）——重构时必须把"倍率链"整体纳入连锁流派预算，跨流派卡之间只允许加法互动

### 2.4 卡组强度四维度（StS 模型）
攻击 / 防御 / 能量 / 运转——精英怪分别考验不同维度（鸟考验防御上限、史莱姆考验AOE、哨卫考验运转）。
**我们的映射**：输出（DEAL_DAMAGE）/ 槽位防御（GAIN_ARMOR 对位）/ 槽位经济（修饰卡、共鸣）/ 序列运转（连锁、换位）。精英怪按维度分别设防。

## 3. 流派构筑理论（机核《一篇硬核讲清流派构筑》）

1. **构筑 = 维度拆分 + 流派设计**；维度越多策略空间越大，但思维负荷上限约 **4-5 个并行流派**
2. **健康流派的卡牌分层**：
   - **基础卡**（下限保障）：流派成型前也有即时战力，暗示方向 → 每流派 2-3 张
   - **上限卡**（质变爽点）：低即时价值高成长 → 每流派 1-2 张稀有
   - **经济/成长卡**：跨回合收益（我们的共鸣增幅全局+1 正是此类）
   - **高成本卡**：爆发终结技
3. **稀有度 = 隐性成本分级**：上限卡放进高稀有度，玩家"憋"上限卡的过程自带风险回报赌感（参考炉石传说"神装"教训：若上限卡无脑强→策略性缺失，需保持基础卡≈上限卡*0.75 的总价值锚）
4. **非定向随机 vs 定向随机**：奖励三选一是定向随机（可放弃），抽牌是非定向——组牌决策点给玩家控制权
5. **卡牌持有成本**：卡组每+1张，抽到关键卡概率下降 → 我们"抽8放5"结构下这个成本更陡峭，奖励必须防止无脑全拿（加入"跳过奖励给小补偿"机制对冲）

## 4. 关键词设计（"关键词即接口"）

- 关键词既是**效果**也是**触发条件**，是卡牌间协同的耦合点（StS：力量既是加成源也被"顺劈斩"引用）
- 新关键词必须与 ≥3 张旧卡产生化学反应，否则只是换皮白板
- STS2 (2026) 实战：Necrobinder 的"召唤"关键词成功 = 资源管理新维度；Regent 被批评 = 子流派与核心机制不咬合 → **新机制必须服务核心循环（我们的位置+序列），不能平行另起炉灶**

## 5. 爽点工程（Balatro 模式）

- **指数增长的多巴胺**：数字从几百滚到几亿——玩家感知的是"倍率链咬合成功"的瞬间
- **Juice 分层**：屏幕震动/粒子/数字放大变色/音效升调，全部作为"正反馈强化"而非装饰；结算慢放 + 数字滚动
- **可解的随机**：随机必须让玩家觉得"我能通过构筑战胜它"（solved randomness）
- **克制**：dopamine 峰值要稀疏——每局 2-3 个"峰值时刻"（首杀精英、Boss 斩杀、combo 爆发），全程高能=没有高能
- 教训（"resist toning down overpowered fun"）：超模组合只要不影响胜率带，宁可保留爽感，砍掉的是"无操作自动赢"的组合

## 6. 意图与敌人设计（StS 模型）

- 意图公示 = 把随机转化为规划：玩家在读意图时就完成了 80% 的策略
- 攻击模式矩阵：单体/多段/AOE/增益/Debuff/蓄力——每种模式对应玩家的一个防御/输出维度
- 精英怪 = 资源兑换站（用 HP 换上限卡），Boss = 毕业考试（多阶段、考验成型流派）
- STS2 教训：anti-infinite 平衡补丁引发社区反弹 → 中后期必须给"数字膨胀"留合法出口（我们的共鸣/连锁全局成长），而不是硬性砍掉

## 7. 位置/序列类游戏设计（Gwent/Duelyst 线）

- Gwent：位置价值——"错误摆放可以使一张卡的价值归零"，位置本身就是资源
- 我们的差异点：**敌人攻击槽位** → 槽位同时是输出位和受击位，位置决策是攻防一体的
- 设计警示：位置复杂度天花板低（5-8槽 vs Gwent 3行×N列），必须让每个位置决策有明确读法（意图公示攻击哪个槽 → 玩家有 1 回合反应时间）

## 8. 对《链式反应》重构的直接指导

1. **卡池结构**：~45 张 = 通用白板 12 + 四流派（连锁/共鸣/反击/焚寂）各 7-8 张（每流派：2-3 基础卡 + 2-3 中坚 + 1-2 上限卡）+ 万能修饰 5-6
2. **稀有度**：普通 60% / 罕见 33% / 稀有 7%；上限卡全部稀有；基础卡全部普通
3. **乘法同族**：REPEAT/MULTIPLY 归连锁流派；共鸣的位置乘区归共鸣流派；反击的格挡转化归反击流派；跨流派只有加法
4. **经济**：奖励可跳过（跳过 +5 金币补偿）；商店删卡价格递增（50/75/100）
5. **难度带**：新手首通 35-50%；标准 75%+；精英 50-65%（敌人数值×1.25，掉落+1）
6. **爽点**：连击计数器（表现层）+ 峰值时刻特效（总伤≥上回合2倍触发"过载"）+ 伤害飘字分级变色
7. **意图**：新增蓄力/自愈/蓄势/双重打击/腐蚀 5 种，连同原有 5 种构成 10 模式矩阵
