## 二、数值预算模型（三层）

### 2.1 进攻预算（TTK 模型）

`DPR(L) = H(L) / TTK(L)`，玩家每回合期望输出 = 敌人血量 ÷ 期望击杀回合数。

| 层 | 节点 | 敌人 HP 带 | TTK | 需求 DPR | 说明 |
|----|------|-----------|-----|---------|------|
| L1 | 战斗 | 42–50 | 3 | **15** | 教学期：12 张初始卡组裸 DPS≈15 |
| L2 | 混合 | 55–75 | 3 | **21** | +2~3 张新卡 |
| L3 | **精英** | 105–125 | 4.5 | **25** | 精英考验单维度（见 2.4） |
| L4 | 混合 | 80–100 | 3.5 | **27** | |
| L5 | 混合 | 100–120 | 3.5 | **32** | |
| L6 | **精英** | 175–205 | 5 | **38** | |
| L7 | **Boss** | 280–330 | 6–8 | **45+峰值 80** | Boss 需要倍率链成型 |

**单槽价值锚**：5 槽满编中约 3 张攻击卡 → 单攻击槽期望 = DPR/3。
普通攻击卡基准伤害 = 10/6/5/4 按曲线；**倍率卡机会成本线 = 1.67×**（占 1 槽换 6 伤卡的门槛：X2 放 6 伤上 = +6 伤 = 刚好及格；连锁/共鸣等乘区卡是超额收益来源，因此设计为需要摆位/排序技巧）。

### 2.2 防守预算（EHP 模型）

| 层 | 敌人 DPR | 单场承伤预算 | 格挡率目标 |
|----|---------|-------------|-----------|
| L1 | 6–8 | 6–12 HP | 60% |
| L2 | 9–12 | 10–18 HP | 65% |
| L3 精英 | 14–18 | 25–38 HP | 65% |
| L4 | 13–16 | 12–20 HP | 70% |
| L5 | 16–20 | 15–25 HP | 70% |
| L6 精英 | 22–26 | 32–45 HP | 70% |
| L7 Boss | 26–34 | 35–55 HP | 70% |

- 全程总承伤 ≈ 150–190 HP，回复资源：休息 2.5 次 ×30 HP + 事件 ≈ 100–120 HP + 牧师技能 → 收支平衡且有紧张感
- 护盾卡基准值 = 敌人 DPR × 0.65 ÷ 1.5 张防御槽（L2: 10×0.65/1.5 ≈ 4.3 → 木盾 5 盾达标）

### 2.3 成长曲线

- 玩家 DPR 每层 +20–30%（新卡/升级/槽位扩建），敌人 HP 每层 +35–45% → 成长期"追平压力"结构，Boss 检验倍率链
- 金币收入：战斗 18–30 + 事件 + 初始 100 ≈ 280–350/局；支出：卡 45–75×3 + 删卡 + 升级

### 2.4 卡组四维度与精英设防（StS 模型）

输出 / 槽位防御 / 槽位经济 / 序列运转：
- **雷暴元素**（L3 精英）：蓄力→爆发，考验**防御峰值**
- **熔岩巨兽**（L3 精英）：全场燃烧，考验**槽位经济**（护盾覆盖 vs 输出换血）
- **时之守卫**（L6 精英）：锁槽+双重打击，考验**序列运转**（换位/共鸣摆位）
- **腐蚀树妖**（L6 精英）：高频低伤多槽攻击，考验**平均格挡**（连锁防线价值）

## 三、关键词体系（四流派）

> 设计原则：关键词即接口（既是效果也是触发条件）；乘法数值同族平衡；跨流派只做加法。

### 3.1 连锁（Chain）—— 排序即强度
**连锁 N**：效果触发 `1 + N × (此牌之前本回合已执行的攻击牌数)` 次。
- 排序奖励显性化：攻击牌越靠左，后面的连锁卡滚雪球越狠
- 乘区归属：与 X2/蓄能（MULTIPLY）构成完整倍率链，**统一在连锁族预算内**
- 数值锚：电弧 5 伤连锁1 = 第1攻击位 5 / 第2位 10 / 第3位 15（期望 3 槽 ≈ 30 伤，2 张电弧+1张 6 伤 ≈ 2.2 槽价值/张，高技巧高回报）

### 3.2 共鸣（Resonance）—— 摆位即强度
**共鸣**：与左右相邻槽位的**同类型**（攻击/护盾）卡互相 +50%。
- 双攻击相邻 → 各 ×1.5；攻击-盾-攻击 → 只有盾吃加成（类型判定）
- 乘区归属：定位仪（共鸣×2 后 ×1.5→×2.25 封顶）
- 与连锁天然张力：连锁要"攻击靠左"，共鸣要"同类相邻"——两种排序哲学

### 3.3 反击（Riposte）—— 承伤即强度
**反击 N**：所在槽位被攻击且**未损失 HP**（格挡或换血 0 溢出）时，对敌人附加 N 伤害（吃结算加成、不吃倍率）。
- 把敌人的意图变成资源：预判准确 = 白嫖伤害
- 数值锚：荆棘甲 4 盾+反击 5；敌人攻击 2 槽时全场反击期望 ≈ 10/回合，等于 1 张攻击卡但零槽位成本（用防御槽兼职输出）

### 3.4 焚身（Burn）—— 生命即资源
**焚身 X**：结算时失去 X 点 HP（最多扣到 1），效果数值翻倍。
- HP 从"血条"变成"第二货币"；与休息/牧师形成经济循环
- 数值锚：血偿 失 4 HP → 16 伤（=2.7 槽效率，代价是承伤预算-4）
- 亡命（HP<50% 时伤害 ×1.5）是焚身族唯一乘区，同族平衡
