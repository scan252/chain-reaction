> 版本：2026-09-12 · 状态：设计定稿 → 实施中
> 前置：v2.1（docs/BALANCE.md）· 模拟器 400 局/配置重跑基线
> 定位：不是微调，是围绕「成长感、峰值感、流派身份」的一次系统性重排

## 〇、v2.1 现状诊断（400 局实测 + 结构归因）

| 配置 | v2.1 实测 | 问题 |
|------|-----------|------|
| 标准·智能 | 69.5% | 失败 81% 堆在 L7 Boss（99/122）——**Boss 是唯一瓶颈墙** |
| 标准·新手 | 47.8% | 合格 |
| 标准·随机 | 0.0% | 合格（技能有表达） |
| 精英·智能 | 44.8% | 合格 |

**流派胜率极差 44.7%**（共鸣 74% / 连锁 64% / 反击 32% / 焚身 29%），比 v2.1 文档记录的 33% 恶化。

### 归因（逐条到机制）

1. **反击流的真正死因不是反击值太低，是"满格挡"几乎不可能**。
   反击触发条件 = 本槽被击且未掉血（盾 ≥ 伤害）。L4-5 敌人单次攻击 8-13，而反击系卡盾值只有 6-12（荆棘甲 6 / 受身 6 / 镜面 12）——中后期盾 < 攻，反击直接哑火。反击卡是"用防御槽兼职输出"，盾值跟不上敌方攻击曲线 = 整个流派曲线性贬值。
2. **焚身流数值密度不足 + 无条件乘区**。
   血偿 20 伤/3 HP ≈ 6.7 伤/HP，对比成型连锁单槽期望 15+；焚身卡还占槽、扣血，双重付息。唯一乘区"亡命"是一次性 ×1.5，全场成长只有血怒 +2/焚身卡。
3. **共鸣"零门槛强"**：同类相邻即 +50%，定位仪再 ×2.5（+125%），无任何风险或排序代价——它是免费的乘区，导致无脑强。
4. **敌方伤害方差 ±30~90%**（如暗影刺客 9±5、虚空之眼 10±9）：意图读取是本游戏的核心技巧，高方差让"读意图摆盾"的期望收益被随机性淹没，惩罚谨慎玩家。
5. **TTK 全程恒定 ≈3 回合**：L1 打史莱姆 3 回合，L5 打深渊猎手还是 3 回合——玩家引擎成型后"变强"只体现在敌人血条变长，爽感无处安放。
6. **峰值带宽窄**：伤害飘字档 [30,60,100,150] 中 ≥100 全程几乎不可达；OVERDRIVE（单回合 ≥50）在成型局也罕见。爽点层形同虚设。
7. **模拟器保真缺陷**：全局成长上限硬编码 12（应为 `KEYWORD.GLOBAL_GROWTH_CAP`）；受身/黄金钟转化值与 gameStore 存在漂移风险。

## 一、设计支柱（v3 五原则）

| 支柱 | 内容 | 度量 |
|------|------|------|
| A. 收益密度重排 | 以"成型 5 槽管线单回合期望"为标尺逐流派锚定：攻击 30-45 / 防御 18-28 / 反击转化 15-25 / 焚身 30-50（付血） | 卡池抽查表 |
| B. 曲线重整 | 前 2 层微降（教学顺滑）、L4-5 持平、精英 L6 微降、Boss HP −8~10% 但单次攻击 +1——**战斗变短、张力不变** | Boss 均回合 6.9 → 5.5±0.5 |
| C. 方差收敛 | 敌方 variance 全线 ≤3（Boss ≤4），让"读意图"成为可靠技巧 | 智能局损血方差下降 |
| D. 峰值重标定 | OVERDRIVE 与飘字档按实测回合伤害分布校准，让"爽点"在成型局以可见频率出现 | 过载率 8-15%/回合 |
| E. 弱流派强化、强流派微削 | 反击盾值对齐敌方攻击曲线、收益 +40~50%；焚身数值 +20%；共鸣定位仪 ×2.5→×2.0 | 流派极差 ≤20% |

**改伤不改骨**：所有改动仅动数值与个别硬编码常量，不动任何机制语义（连锁/共鸣/反击/焚身的触发规则一字不改）。

## 四、迭代记录

### v3.0 首轮（方案值直出）
过热：智能 91.0% / 新手 79.3% / 精英 67.8%；流派极差 22.7%（BURN 61.3 垫底）。
归因：方差收敛的收益被低估——确定性意图让"完美格挡"近乎无伤，等于给全体玩家发了一件隐形遗物。

### v3.1 二轮（模板层回填）
L4-L7 敌人基础伤害 +1、HP +4~8；焚身重复衰减 ×0.6 → ×0.7。
结果：智能 84.5% / 新手 72.3% / 精英 49.8%；流派 65.3/77.3/62.7/51.3（极差 26%）。
精英难度已进带，普通难度仍过热 → 需要"全局"刻度而非继续逐模板加码。

### v3.2 三轮（难度系数回填，终稿）
`DIFFICULTY.NORMAL {hpMul 1.12, dmgMul 1.06}`、`ELITE {1.28, 1.16}`——方差收敛后的全局威胁度回填，一处系数替代 14 个模板的二次加码。

### 遗留观察项（Live Balance）
1. Boss 仍承担约 3/4 的智能局失败——保留"终考"定位，若真实玩家数据同样收敛于此，考虑给 L6 精英后增加一个休整节点而非削 Boss。
2. BURN 42% 为四流派地板，但已从 29% 大幅修复；其"HP 税"结构决定上限，继续观察。
3. 随机策略 0.3% 在 L3 精英集中死亡（252/400）——精英作为构筑检验点的表达符合预期。
